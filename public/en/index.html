Using this tool

How many copies are printed for each name?

One copy count applies to every nonblank line. Copies of one name are grouped together before the next name.

Can I use this with pre-cut label sheets?

The presets are for labels printed on plain A4 or Letter paper and cut by hand. They are not calibrated for a specific pre-cut label brand or model.

How can I keep the printed size close to the layout?

Select the matching paper, use 100% scale, and turn off headers and footers. Printer margins can still affect the result, so measure a plain-paper test first.

Is my list saved or uploaded?

This version processes the list in the current page and does not save or upload it. The first page load still downloads static website files.

A loaded tab can calculate locally; a first load while offline is not guaranteed.
