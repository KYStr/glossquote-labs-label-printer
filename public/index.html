物品標籤列印

把物品名稱逐行貼上，設定每個名稱要印幾份，選擇 A4 或 Letter 普通紙版型，建立預覽後列印裁切。

這是普通紙裁切用版型，不是特定品牌預裁貼紙套版。瀏覽器、列印縮放和印表機可能影響實際尺寸。

名稱與版型

每行一個名稱；空白行會略過。每個名稱使用相同份數，請輸入 1–20。每行最多 80 個 Unicode code points，全部展開最多 300 張標籤。

整份清單最多 10 KiB（UTF-8），包含空白及換行。

1–20；同一份數套用到所有名稱。

頁面預覽

先核對名稱順序、每項份數、版型和頁數。最後一頁未用格會保持空白。

尚未建立預覽。貼上名稱並建立預覽後，標籤頁會顯示在這裡。

A4 / Letter

紙張以實際版面比例呈現；小螢幕可在標籤頁區域內捲動。

請選擇相同紙張、縮放 100%，並關閉頁首頁尾。先用普通紙試印，量測後再裁切。

原生列印預覽與實際紙張尺寸尚未驗證。手機列印依裝置支援。

使用說明

每個名稱會印幾份？

所有非空白行共用同一個份數；每個名稱的副本會連在一起，再排下一個名稱。

這可以套用到預裁貼紙嗎？

這是 A4 或 Letter 普通紙裁切用版型，不保證符合任何品牌或型號的預裁貼紙。

怎麼讓實際尺寸更接近版面？

列印時選擇相同紙張、縮放 100%、關閉頁首頁尾；印表機不可列印邊界仍可能影響結果，請先用普通紙量測。

輸入清單會保存或上傳嗎？

本版只在目前頁面記憶體處理，不保存或上傳；第一次開頁仍需下載網站靜態檔案。
