# 物品標籤列印（Item Label Printer）

狀態：**M0 規格，尚未實作、驗收或發布。** 本資料夾的文件定義第一版工作範圍，不代表已有可用網站。

## 使用者工作

把物品名稱逐行貼上，設定每個名稱要印幾份，選擇 A4 或 Letter 普通紙版型，產生可列印的標籤頁，再手動裁切。每個物品的副本會排在一起，名稱順序和重複項目都保留。

第一版只有四種固定版型：A4 2 欄 × 7 列、A4 3 欄 × 8 列、Letter 2 欄 × 7 列、Letter 3 欄 × 8 列。頁邊 10 mm、標籤間隙 2 mm。這些是普通紙標籤頁，不是特定品牌的預裁貼紙套版；瀏覽器縮放和印表機可能影響實際尺寸，需使用列印縮放 100%、關閉頁首頁尾，並先用普通紙核對。

## 初版範圍

- 繁體中文和英文各有完整頁面、說明、錯誤、FAQ 與同語首頁連結。
- Node.js 24+、ESM、原生 HTML/CSS/JavaScript 和 built-ins；沒有 runtime、開發或測試套件依賴。
- 所有輸入只在目前頁面記憶體處理；不儲存、不上傳、不寫入 URL，也不加遙測或外部字型。
- 只有明確產生預覽後才能呼叫瀏覽器列印；本版不提供下載、剪貼簿或自動列印。
- 預覽預設空白，範例只能由使用者明確載入；修改後舊預覽立即失效。

不做商用預裁貼紙精準套版、QR code、條碼、圖片上傳、保存草稿或雲端同步。正式網址候選是 https://labels.glossquote.com；M0/M1 不代表網域、原生列印或正式站已驗證。M1 本機預覽使用 127.0.0.1:4210，production-like 模型使用 127.0.0.1:5210。
